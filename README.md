# विधि (Vidhi) — Legal Notice Explainer

A plain-language explainer for Indian legal notices, built for people who
receive a notice they don't understand and can't afford a lawyer to explain
it. Upload a photo or scan of a notice, and get back what it means, which
law it's based on, what to do next, and whether you need a lawyer at all.

Built as a solo project to learn full-stack + applied AI development.

## The problem

Legal notices in India are written in dense, Latin-heavy legal language.
Understanding one usually means paying a lawyer just for a first read.
Generic AI chatbots often get Indian-law specifics wrong because they
aren't grounded in the actual statutes.

## What this does

- **OCR** — extracts text from an uploaded photo/scan of a notice
  (Tesseract)
- **RAG pipeline** — matches the notice against a small reference set of
  actual Indian statutes (Negotiable Instruments Act §138, Consumer
  Protection Act, CPC, common legal terms) using embeddings, rather than
  letting the LLM guess from training data
- **Plain-language explanation** — generated by Gemini, grounded in the
  retrieved statute text, with a fixed structure: what it is, what it means
  for you, what to do, and a confidence indicator
- **Fraud/authenticity checker** — a separate, standalone rule-based check
  for whether a notice looks genuine or like a scam (pressure language,
  missing reference numbers, suspicious payment requests)
- **Free legal aid routing** — automatically surfaces NALSA's free legal
  aid helpline (15100) when a case involves potential criminal
  consequences
- **Cost estimate** — a rough, sourced fee range for cases where a lawyer
  is likely needed

## What this isn't (yet)

Honest scope — not all originally planned features are built:
- No regional language translation yet (attempted, not currently working)
- No notice-type classifier as a dedicated feature
- No precedent reference
- No audio explanation mode
- No community-verified glossary
- Statute coverage is currently limited to a handful of common notice
  types (cheque bounce, consumer disputes, civil summons) — not a full
  legal database

This does not draft or send legal notices, and is not a substitute for
legal advice.

## Tech stack

**Frontend:** React (Vite), plain CSS, no UI framework
**Backend:** FastAPI (Python)
**OCR:** Tesseract via pytesseract
**LLM / embeddings:** Google Gemini (`gemini-2.5-flash` generation,
`gemini-embedding-001` embeddings) via the `google-genai` SDK
**RAG:** No vector database — statute embeddings are cached to a local
JSON file and matched with cosine similarity (numpy), since the reference
set is small

## Running it locally

### Backend
```
cd vidhi-backend/vidhi-backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```
Copy `.env.example` to `.env` and add a Gemini API key (free tier at
[ai.google.dev](https://ai.google.dev)). Tesseract OCR must also be
installed separately on the system — see the README inside that folder.

```
uvicorn app.main:app --port 8000
```

### Frontend
```
npm install
npm run dev
```

Both need to run at the same time — backend on `:8000`, frontend on
`:5173`.
